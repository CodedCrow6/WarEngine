# WAR ENGINE

A modular military sandbox and battlefield simulation developed using Godot 4 and GDScript.

## Project Status

Initial project foundation and architecture development.

## Development Principles

- Modular system architecture.
- Independent system testing.
- Explicit dependencies and interfaces.
- Documented functionality.
- Version-controlled development.
- Incremental feature integration.

## Engine

Godot 4.x

## Project Vision

A persistent, autonomous military battlefield simulation where players participate in an independently operating military organisation, progress through military careers, and influence the battlefield through their roles and responsibilities.

Current milestone: Project Foundation
